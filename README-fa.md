# قسط‌یار نسخه ۳.۶.۱ — تشخیص خطاهای Push

این نسخه فقط پیام خطاهای تابع `ghestyar-push-subscribe` را دقیق‌تر کرده است.
جدول‌های مالی، منطق حساب کاربری، تنظیمات Supabase و Cron تغییری نکرده‌اند.

## انتشار
فقط `index.html` جدید را در ریشه GitHub جایگزین کنید.
فایل‌های دیگر در بسته صرفاً برای انتشار کامل افزوده شده‌اند.

## بررسی خطا
پس از انتشار، دوباره روی «فعال‌کردن Push» بزنید.
- HTTP 401/403: ورود و گزینه Verify JWT در اولین تابع را بررسی کنید.
- HTTP 404: نام تابع و انتشار آن را بررسی کنید.
- HTTP 500/503: بخش Logs و Secrets را بررسی کنید.
- خطای شبکه یا CORS: بخش Invocations و سربرگ‌های CORS را بررسی کنید.

هیچ کلید خصوصی یا توکن ورود را در گفتگو/اسکرین‌شات ارسال نکنید.
