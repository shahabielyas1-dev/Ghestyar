# قسط‌یار ۴.۴ — Neon Blue / بازطراحی عمیق رابط کاربری

## تغییرات اصلی

- زبان بصری جدید مشابه طرح تأییدشده: سرمه‌ای عمیق، کارت‌های آبی شیشه‌ای، نورپردازی محدود و تایپوگرافی فارسی با حفظ دسترس‌پذیری.
- بازطراحی ساختار واقعی داشبورد: کارت مانده کل تعهدات، آمار پرداخت‌شده/اقساط/تعهدات، پرداخت بعدی، تایم‌لاین سررسید، جمع‌بندی ماه و نمودار ۶ ماهه بر اساس پرداخت واقعی.
- بازطراحی سربرگ و سایدبار دسکتاپ و نوار پایین موبایل با دکمه برجسته «افزودن».
- یکپارچه‌سازی بصری فرم تعهد، صفحات تعهدات و جزئیات، تقویم شمسی، گزارش‌ها، تنظیمات، پنجره‌های پرداخت و نصب برنامه.
- طراحی لوگوی جدید قسط‌یار به صورت SVG و آیکون‌های PNG با هویت کیف پول آبی نورانی.
- رنگ‌بندی روشن هم متناسب با هویت بصری جدید تنظیم شده است.

## انتشار روی GitHub Pages

۱. **قبل از هر کاری از اطلاعات مالی خود فایل JSON پشتیبان بگیرید و در جایی خارج از مرورگر نگهداری کنید.**
۲. در مخزن GitHub که GitHub Pages از آن منتشر می‌شود، این ۵ فایل را در کنار یکدیگر در ریشه مخزن بارگذاری/جایگزین کنید:

  - `index.html`
  - `logo.svg` (جدید)
  - `icon-192.png`
  - `icon-512.png`
  - `manifest.webmanifest`

۳. فایل‌های `ghestyar-config.js` و `reminder-sw.js` موجود را **دست‌نخورده نگه دارید**؛ داخل بسته کامل نسخه‌های یکسان آن‌ها جهت مرجع هم وجود دارد. هیچ تنظیم SQL یا Supabase نیاز به تغییر ندارد.
۴. پس از Commit شدن، صفحه را یک‌بار با Refresh باز کنید. اگر برنامه از قبل نصب شده، آن را کاملاً ببندید و دوباره باز کنید. ممکن است آیکون تازه با تأخیرِ کش مرورگر/سیستم عامل نمایش داده شود.
۵. ابتدا بدون ثبت پرداخت جدید، مجموع مانده و تعداد تعهدات را با نسخه پشتیبان تطبیق دهید. سپس مسیرهای «تعهدات»، «تقویم»، «ثبت تعهد» و «جزئیات» را بررسی کنید.

## محدودیت‌ها و صحت آزمون

- کد اصلی اطلاعات مالی، محاسبه اقساط، ذخیره‌سازی، همگام‌سازی Supabase و Push از نسخه ۴.۳ حفظ شده است؛ نسخه ۴.۴ مهاجرت داده انجام نمی‌دهد.
- ۱۵ سناریوی مستقل منطق مالی (پرداخت ناقص، ابطال، تسویه یکجا، مدل‌های وام و کنترل صحت داده) موفق بود.
- صحت نحو JavaScript و قواعد CSS، تولید HTML صفحه اصلی با داده آزمایشی و HTML ناوبری بررسی شده است.
- **آزمون مرورگری تعاملی و اتصال واقعی Supabase در این محیط انجام نشد**: ابزار مرورگر محیط از بازکردن صفحه آزمایشی جلوگیری کرد. بنابراین بعد از انتشار، سناریوهای واقعی باید روی گوشی تأیید شوند.
- این بازطراحی از تصاویر مرجع الهام گرفته و کپی پیکسلی تصاویر نیست؛ کارت‌ها و عملیات با منطق واقعی قسط‌یار هماهنگ‌اند.

## ساختار فایل‌ها

- `index.html`: برنامه اصلی و طراحی جدید
- `logo.svg`: لوگوی برداری قابل بزرگ‌نمایی
- `icon-192.png` و `icon-512.png`: آیکون نصب و صفحه اصلی
- `manifest.webmanifest`: اطلاعات PWA
- `ghestyar-config.js`: تنظیمات اتصال عمومی Supabase (بدون کلید محرمانه)
- `reminder-sw.js`: سرویس دریافت اعلان پس‌زمینه (تغییر نکرده)
