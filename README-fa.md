# نسخه ۳.۹.۱ — نصب قسط‌یار روی گوشی

## تغییرات
- پاپ‌آپ نصب متناسب با هویت گرافیتی و سبز لیمویی
- اندروید Chrome/Edge: نصب مستقیم فقط وقتی مرورگر رویداد `beforeinstallprompt` ارائه کند؛ در غیر این صورت راهنمای نصب دستی
- آیفون Safari: راهنمای افزودن به Home Screen، بدون ادعای نصب خودکار
- مرورگرهای iOS دیگر: راهنمای بازکردن سایت در Safari
- عدم نمایش پاپ‌آپ در حالت نصب‌شده (standalone)
- ذخیره وضعیت «فعلاً نه» به مدت ۲۱ روز در مرورگر
- امکان بازکردن دوباره از تنظیمات
- بدون تغییر در منطق ذخیره اقساط، پرداخت، Supabase یا Push

## انتشار در GitHub Pages
1. از اطلاعات مالی در برنامه پشتیبان JSON بگیر.
2. فقط `index.html` جدید را در ریشه مخزن `Ghestyar` جایگزین کن.
3. فایل‌های `manifest.webmanifest`، `icon-192.png`، `icon-512.png` و `reminder-sw.js` باید از نسخه ۳.۹ موجود باشند. در بسته ZIP هم آمده‌اند.
4. `ghestyar-config.js` فعلی را دستکاری نکن؛ هیچ کلید محرمانه‌ای در GitHub قرار نده.
5. در Chrome Android، سایت را باز و چند ثانیه در داشبورد بمان؛ اگر نصب مستقیم ممکن باشد دکمه «نصب برنامه» پنجره رسمی مرورگر را باز می‌کند. در غیر این صورت مراحل نصب دستی دیده می‌شود.
6. اگر نصب را رد کردی، برای دسترسی مجدد وارد تنظیمات قسط‌یار شو و «راهنمای نصب برنامه» را بزن.

**نکته**: شرایط نصب به مرورگر، HTTPS، Manifest و رفتار سیستم‌عامل بستگی دارد. روی iOS نصب مستقیم با JavaScript امکان‌پذیر نیست. نصب برنامه، داده‌های مالی را خودکار پاک یا منتقل نمی‌کند؛ حساب ابری خودت را بررسی کن.
