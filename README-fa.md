# قسط‌یار ۴.۱.۱ — حذف امن تعهد

این نسخه بر پایهٔ قسط‌یار ۴.۰ ساخته شده و بهبودهای حفاظت از اطلاعات ۴.۱ را نیز شامل می‌شود. هیچ جدول جدیدی در Supabase یا تغییر در توابع Push لازم نیست.

## حذف تعهد
۱. از «تعهدات»، تعهد اشتباه را باز کن.
۲. روی «حذف تعهد» بزن. صفحه تأیید نام، تعداد اقساط، مبلغ کل و سوابق پرداخت را نشان می‌دهد.
۳. اگر سابقه پرداخت وجود دارد، برای جلوگیری از حذف تصادفی باید نام دقیق تعهد را تایپ کنی.
۴. قبل از حذف، یک نسخه اضطراری از تمام اطلاعات در حافظه همان دستگاه و حساب ساخته می‌شود. اگر این کار شکست بخورد، حذف متوقف می‌شود.
۵. اگر وارد حساب ابری شده‌ای، ابتدا همگام‌سازی باید کامل باشد. بعد از حذف، تغییر به ابر فرستاده می‌شود.
۶. برای بازیابی، تنظیمات > ابزارهای پیشرفته > بازیابی تعهد حذف‌شده را باز کن. تا سه نسخه اضطراری آخر در همین مرورگر ذخیره می‌شوند؛ این نسخه‌ها با پاک‌کردن حافظه مرورگر از دست می‌روند.

## هشدار
حذف یک تعهد تمامی اقساط و سوابق پرداخت مربوط به آن را از پرونده فعال و پس از همگام‌سازی از ابر حذف می‌کند. بازیابی از نسخه اضطراری فقط تا زمانی ممکن است که نسخه مربوط در مرورگر باقی بماند. قبل از انتشار و حذف، پشتیبان JSON قابل دانلود بگیر و نگهداری کن. برای تعهد واقعی که فقط عنوان یا جزئیاتش اشتباه است، ویرایش بهتر از حذف است.

## انتشار
از GitHub Pages، فقط `index.html` را در ریشه مخزن با نسخه جدید جایگزین کن. فایل‌های دیگر تغییر نکرده‌اند. اگر خواستی بسته کامل را منتشر کنی، `ghestyar-config.js` حاوی کلید عمومی است و نباید هیچ کلید service_role یا VAPID خصوصی را در GitHub آپلود کنی.

## آزمون
آزمون‌های محلی روی حذف، بازیابی، سابقه پرداخت، و خطاهای ذخیره/همگام‌سازی انجام می‌شوند؛ حساب واقعی Supabase و Push روی گوشی نیاز به تأیید خودت دارد.
