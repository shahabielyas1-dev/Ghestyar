# قسط‌یار ۳.۸ — بازطراحی گرافیکی Graphite & Lime

طراحی نسخه ۳.۸ با الهام از تصویر مرجع ارسال‌شده: **سرمه‌ای گرافیتی، کارت‌های لایه‌ای، سبز لیمویی برای عملکردهای اصلی، کلیدهای بزرگ لمسی و نوار ناوبری شناور موبایل**. طراحی از تصویر ایده گرفته و محتوای آن برای مدیریت تعهدات و اقساط فارسی و راست‌به‌چپ بازآرایی شده است.

## تغییرات

- به‌روزرسانی نمای تاریک و روشن با کنتراست متفاوت و فونت وزیرمتن؛ حالت تاریک برای کاربر تازه پیش‌فرض است و انتخاب ذخیره‌شده کاربران فعلی حفظ می‌شود.
- کارت اصلی ماه با نمایش مانده و پیشرفت پرداخت و **چهار میان‌بُر فعال**: ثبت پرداخت سررسید اول، تعهد جدید، تقویم، گزارش‌ها.
- بازآرایی کارت قسط اول، شاخص‌های مالی، فهرست پرداخت‌ها، فیلترها و کارت‌های تعهد.
- تبدیل ناوبری موبایل به نوار شناور قرصی با نشان‌دادن عنوان گزینه فعال؛ اصلاح محل عنوان صفحه برای جلوگیری از قطع‌شدن آن در گوشی.
- تغییر آیکون نصب وب‌اپ و رنگ manifest به تم جدید.
- هیچ تغییری در منطق محاسبات مالی، پایگاه داده، Edge Functions، Vault، Cron، Service Worker یا کلیدهای اتصال ایجاد نشده است.

## انتشار با موبایل در GitHub Pages

1. **قبل از هر تغییری** از قسط‌یار یک فایل پشتیبان JSON بگیر و وضعیت همگام‌سازی را بررسی کن.
2. وارد مخزن `shahabielyas1-dev/Ghestyar` شو. از این بسته در ریشه مخزن **فقط فایل‌های زیر** را جایگزین کن:
   - `index.html` (الزامی برای بازطراحی)
   - `icon-192.png` و `icon-512.png` (آیکون جدید)
   - `manifest.webmanifest` (رنگ نصب برنامه)
3. `ghestyar-config.js` و `reminder-sw.js` را **تغییر نده**؛ همان نسخه‌های فعلی باید باقی بمانند. نسخه سازگار آنها در بسته نیز قرار گرفته است.
4. در GitHub روی Commit changes بزن و پس از انتشار سایت، یک‌بار صفحه را تازه‌سازی کن. اگر وب‌اپ نصب است ممکن است برای دیدن آیکون جدید لازم شود میان‌بر قبلی را حذف و دوباره نصب کنی.
5. ابتدا ورود/حساب من، فهرست اقساط قدیمی، نمایش مبلغ‌ها، فرم ثبت پرداخت، تم روشن و تیره و همگام‌سازی را بررسی کن.

**مهم:** ZIP را به‌عنوان یک فایل داخل ریشه مخزن آپلود نکن؛ محتویات آن باید جایگزین فایل‌های فعلی شوند. از انتقال کلیدهای خصوصی یا پوشه‌های backend به GitHub خودداری کن.

## آزمون‌ها و محدودیت‌ها

- هفت اندازه صفحه: ۳۲۰، ۳۶۰، ۳۹۳، ۴۳۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل، بدون اسکرول افقی و خطای JavaScript در حالت آزمایشی.
- ثبت پرداخت از میان‌بر و بازشدن فرم تعهد، تغییر تم و چهار میان‌بر کنترل شد.
- ۳۴ آزمون برگشتی مرتبط با فرم‌ها، وضعیت همگام‌سازی، عدم بازنویسی داده‌ها، پرداخت ناقص و ابطال پرداخت موفق بودند.
- **آزمون زنده حساب Supabase، اعلان Push هنگام بسته بودن برنامه و دریافت واقعی روی گوشی** در این محیط انجام نشده‌اند. آزمون اعلان صبح همچنان باز است.
- تصویر پیش‌نمایش از داده‌های ساختگی برای نمایش ظاهر استفاده می‌کند و به حساب واقعی متصل نشده است.
