# قسط‌یار ۴.۰ — نسخه شخصی «ساده اما کامل»

## تغییرات
- خانه جدید: مانده همین ماه، قسط بعدی، ثبت پرداخت سریع و چهار سررسید در ۳۰ روز آینده.
- ناوبری موبایل: خانه، تعهدات، تقویم و افزودن؛ گزارش‌ها/یادآوری‌ها/مدیریت داده در تنظیمات.
- سربرگ خلوت با اعلان، تنظیمات و وضعیت کوچک همگام‌سازی.
- افزودن تعهد: پیش‌فرض خرید اقساطی؛ محاسبات ویژه فقط برای وام بانکی.
- تنظیمات شخصی: گزارش‌ها، یادآوری‌ها، تغییر تم، حساب و پشتیبان در دسترس، امکانات پیشرفته در بخش تاشو.
- بدون تغییر در ساختار داده، نام جدول‌های Supabase، عملیات پرداخت یا کد Push.

## نصب امن روی GitHub Pages
1. از داخل قسط‌یار خروجی پشتیبان JSON بگیر و فایل را روی گوشی نگهدار.
2. فقط `index.html` را در ریشه مخزن جایگزین کن. سایر فایل‌ها و کلیدهای انتشار سرور را تغییر نده.
3. سایت را باز/Refresh کن و ورود، اقساط فعلی، قسط بعدی، ثبت پرداخت و همگام‌سازی را بررسی کن.
4. اگر نسخه قبلی در کش ماند، یک‌بار در صفحه وب Reload انجام بده.

**توجه:** هیچ تغییری در حساب آنلاین/اطلاعات واقعی کاربر از طرف این نسخه اجرا نشده؛ آزمون آنلاین نیازمند بررسی روی سایت منتشرشده است.
